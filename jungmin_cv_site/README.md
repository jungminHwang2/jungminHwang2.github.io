# Jungmin Hwang Academic CV

Static academic CV website for GitHub Pages.

## Files

- `index.html` — page content
- `styles.css` — visual design and responsive layout
- `theme.js` — dark/light theme toggle
- `profile-placeholder.svg` — temporary profile image

## How to publish

Upload these files to the root of the `jungminHwang2.github.io` repository.
GitHub Pages should be configured to deploy from `main` / `(root)`.

## What to edit first

1. Replace `YOUR_EMAIL@example.com`.
2. Add Google Scholar / ORCID URLs.
3. Correct the Education section.
4. Replace publication placeholders with exact citation information.
5. Upload your portrait as `profile.jpg` and change:
   `src="profile-placeholder.svg"` → `src="profile.jpg"`
